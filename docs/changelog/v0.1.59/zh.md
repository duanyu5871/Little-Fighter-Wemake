### 新东西

- 联机昵称：连接面板可填（最多 10 字，自动记住），准备界面、指针等处都会显示
  - 联机中随时可改：设置面板（齿轮）→「杂项」顶部新增昵称输入
  - 没设置过会自动生成一个：按系统语言从英文 / 中文词池里随机「形容词 + 名词」组合
- 鼠标操作全面启用：联机对局中也能用鼠标点击 / 悬停界面（此前联机时被禁用）
  - 指针旁显示操作者昵称，联机时一眼看出「谁点的」
  - 本机光标改为独立渲染并去掉缓动，移动更跟手（远端指针保留平滑过渡）
  - 远端指针停留时间放宽（2 秒 → 5 秒），消失前渐隐 1 秒，不再突然消失
- 出招表：角色名两侧新增 ◀ ▶ 按钮，鼠标点击切换角色（等同键盘 L / R）
- 联机房间列表改版：支持分页，工具栏换成图标按钮（新建 / 刷新 / 自动刷新 / 断开），房间卡片重新排版
- 桌面客户端
  - 检查更新与下载进度改在游戏页面右下角显示（不再弹窗打断），下载完成可点「重启安装」
  - Ctrl+Shift+I 随时开关开发者工具（游戏与工具窗口），托盘菜单也加了入口
  - 托盘新增「打开预览器」，预览页里可再返回游戏；关闭游戏窗口时整体退出，不再残留进程

### 调整

- 内存与性能优化：BGM 改为流式播放（不再整首解码进内存）；贴图 / 背景 / 阴影等渲染占用下降；角色控制器池化复用
- 数据包加载进度改为整体百分比显示
- 开发工具预览器：「图片」页重做为「资源」页，可预览 3D 模型、显示文件大小；桌面端窗口控件与游戏页统一
- 发布流程（GitHub Actions）：手动触发时部署目标（GitHub Release / GitHub Pages / lf.gim.ink）改为各自独立勾选，可与「复用构建产物」任意组合，无需重新构建
- 修复：被快速连续命中时，角色可能长时间卡在同一帧
- 修复：在输入框中打字时，按键会同时触发游戏内操作
- 修复：联机面板（连接 / 房间列表 / 房间信息）改为固定居中浮层显示，避免位置偏移与多余内边距
- 修复：切换语言后，联机窗口（连接面板 / 房间列表等）的语言没有跟着变
