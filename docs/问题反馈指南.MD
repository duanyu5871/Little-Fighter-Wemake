# 问题反馈指南

[中文](./问题反馈指南.MD) | [English](./问题反馈指南.EN.MD)

一条能被快速处理的问题反馈 = **版本 + 环境 + 复现步骤 + 期望/实际 + 证据**，而且**一次给全**——不要挤牙膏式地一条一条补，信息完整处理起来快得多。

**去哪里提**：推荐开 **GitHub Issue** → <https://github.com/gimhol/Little-Fighter-Wemake/issues>（方便跟踪进度、方便补充信息）；拿不准是不是 bug、或者想先讨论，可以发到 [Discussions](https://github.com/gimhol/Little-Fighter-Wemake/discussions) 或群里。提之前先搜一下有没有相同的问题，有就补充在原帖。

**欢迎积极反馈**：目前反馈数量还不多，**每一条都会看**。不用担心问题太小、看不懂哪出的错、或者拿不准算不算 bug，尽管提；这份指南只是为了让问题更容易被定位，不是门槛。

**能配动图（GIF）或截图就配上**——"操作 → 出问题"的几秒动图最有用，动图可以用 [ScreenToGif](https://www.screentogif.com/)（Windows，免费开源）录制并直接导出。

下面逐项说明"要写什么、怎么拿到"。写不全也没关系，能填多少填多少，但**版本和复现步骤**最好别省。

## 0. 先做三个快速排查

很多"问题"是缓存或环境导致的，先花一分钟排除：

- **强刷页面**再试一次：`Ctrl + F5`（Mac：`Cmd + Shift + R`），或用无痕窗口打开。
  旧页面配新数据包是最常见的"诡异现象"来源。
- **换原版数据再试一次**：如果你替换过数据包、或用过"自定义游戏"、装过自制角色，先用官方数据复现。
- **换个浏览器/设备**试一次：能区分"所有人都有的问题"和"你这边环境的问题"。

## 1. 版本信息（必写）

- 启动页/主页**屏幕底部**有一行小字，形如：

  ```
  v0.1.51-59c3450-dirty 2026-09-19 22:51:28
  ```

  连后面的构建时间一起写上（截图也行）。
- 说明你玩的是哪个版本：
  - 正式版（lf.gim.ink）
  - 预览版（GitHub Pages）
  - 谷歌浏览器扩展
  - B站 Toy 版

版本不一样，问题很可能已经修了或者压根不在同一份代码上。

## 2. 环境（必写）

- **系统**：Windows 10/11、macOS、Android 几、iOS 几……
- **浏览器**：Chrome 141 / Edge / Firefox / Safari ……（手机自带浏览器请写清楚型号）
- **输入方式**：键盘 / 触屏虚拟手柄

## 3. 复现步骤（最重要）

目标是让别人**照着做能复现**。请写清楚：

- **模式**：闯关 / 对决 / 生存排行（单人/双人）/ 联机
- **关卡/地图**：例如"雪地"、"生存第 5 波"
- **角色与招式**：例如"用 Henry 射箭"、"Julian D>A"
  - 角色、招式、道具的名字在不同语言/地区叫法不一样（同一个招式在不同圈子里可能完全对不上号），描述招式时尽量用**按键组合**（如 `D>A`），或在截图上圈出来，避免对不上号
- **具体步骤**：`1. … 2. … 3. …`
- **期望结果** vs **实际结果**
- **频率**：必现？还是大约几局出一次？偶发的问题请写出"什么情况下更容易出现"

有 **动图/视频** 的话，一段 5 秒的录屏胜过一段文字。动图推荐用 [ScreenToGif](https://www.screentogif.com/)（Windows，免费开源，录完直接导出 GIF）；其他平台用系统录屏也可以：

- Windows：`Win + G` 或 `Win + Alt + R`
- macOS：`Cmd + Shift + 5`
- 手机：系统自带的屏幕录制

## 4. 证据（有就贴）

- **动图（GIF）/截图**：报错弹窗、黑屏、白块、数值异常、画面错位等——能录成动图更好（推荐 [ScreenToGif](https://www.screentogif.com/)）
- **控制台报错**（电脑上）：`F12` → `Console` 面板 → 把红字**整段复制**贴上来（截图也可以）
  - 看不懂没关系，全贴就行，作者会自己筛
  - 手机浏览器没有控制台，写清楚手机型号和现象即可
- **卡顿/掉帧**：设置里打开「性能数据」，截图显示出来的帧率/延迟
- **联机不同步**：说明是"只有一个人卡"还是"所有人都卡"，以及各自看到的现象

## 5. 这些情况请特别注明

- **用过来路不明的数据包 / 改过的角色**：先说清楚，否则八成不是引擎的问题
- **用的是预览版或某个 tag 构建**：问题可能已经修了
- **B站 Toy 版**和网页版的表现差异：注明你是在 B站里玩的
- **偶发问题**：写出出现的大致时间点（比如"玩了半小时后开始"）和之前做了什么

## 6. 可以直接抄的模板

```
【版本】v0.1.51-XXXXXXXX（正式版 / 预览版 / 扩展 / B站）
【环境】Windows 11 + Chrome 141 / 键鼠
【模式】生存（单人）
【角色】Louis，跑攻（雷击）
【复现步骤】
1. 进入生存排行，选 Louis
2. 对敌人使用跑攻
3. 敌人被电后原地不动
【期望】敌人应该被电击后僵直
【实际】敌人完全不动，也没有特效
【频率】必现
【附件】动图/截图：xxx；控制台无报错
【补充】没有改过数据包
```

## 7. 小贴士

- **一条反馈里把信息一次给全**：版本、环境、步骤、证据一口气写完；不要先发一句"有个 bug"再等人追问
- **一个问题一条反馈**，不要一条里塞五个问题
- 有后续信息（比如换了版本后不复现了）**直接补充在原处**，别另开新帖
- 如果作者追问细节（比如某个具体版本、某段日志），请留意回复，这类问题通常就差最后一步信息就能修
- 「表现和原版 LF2 不一样」不一定是 bug，可以先看看 [对于与LF2表现差异的看法](./对于与LF2表现差异的看法.MD)
