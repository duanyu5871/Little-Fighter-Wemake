# 对于与LF2表现差异的看法

[中文](./对于与LF2表现差异的看法.MD) | [English](./对于与LF2表现差异的看法.EN.MD)

非常遗憾，该项目并非通过反编译实现，而且其更新率为60帧/秒，因此“完全还原原版行为”成了难如登天的事。

等代码架构稳定之后，再回头想办法参考原版代码，也很难做到了。

---

举个不恰当的例子：电影版的蜘蛛侠，有三位主演，三个系列。

三个系列给观众带来的感受完全不同，唯一一样的可能就只有角色名与一些人物关系。

LFW 大概也是这样：名字还是那些名字，招式还是那些招式，但“手感”这种由无数细节堆起来的东西，很难靠黑盒复刻做到完全一致。

在早期的开发中，我有时候过于追求“让原版角色的某些连招成立”。

不断调整参数，结果又导致别的连招不成立了；甚至还冒出了新的连招，比如“镰刀可连续命中”。按下葫芦浮起瓢，最后能确认的只有一件事：在代码差异下，靠调参数去逼近原版行为，是一条没有尽头的路。

像“镰刀可连续命中”这种副产品，不一定非要当 bug 灭掉。只要不是恶性破坏（卡死、崩档），它也可能是一颗新的玩法种子。留还是改，取决于它对游戏是好是坏，而不是“原版有没有”。

当然针对各种改档里冒出来的、原版数据里没有的“技巧”，该支持还是要支持的。

---

说到底，还是希望各位在还原原版这件事上，对 LFW 的期待能放低一些。

当然，这绝不是说主观感受不重要——恰恰相反：玩惯了原版，对节奏、手感的直觉是在无数局里养成的，“感觉不对”本身就是最真实的体验，我完全能理解，也愿意听。只是希望各位把它当作“不同”，而不是直接判成“错”。

另外完全欢迎各位fork并发起pull request。不过得先坦白：我的代码风格比较混乱，请多包涵。

而这在AI的面前似乎成了很小的问题——任何人都可以轻易地把它改成自己想要的样子，其中当然也包括往里加新东西。

一个只靠“还原”的项目是有天花板的——原版的东西总会被做得差不多，而游戏要一直好玩下去，就得能装下新的东西：新角色、新招式、新机制，甚至是原版根本做不出来的玩法。想保持活力，就不能没有新内容。给 LFW 加新内容，唯一的前提是别破坏默认体验。

最后，也不希望 LFW 给原版招来批判——它无意贬低原版，问题也只属于它自己。
